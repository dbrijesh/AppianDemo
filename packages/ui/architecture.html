📐 StateGraph Architecture
Typed state schema (TypedDict / Pydantic). Nodes are pure async functions receiving state → returning partial update. Edges: static, conditional (router function), or parallel fan-out. Compiled graph is reusable across invocations.
TypedDict StatePure Functions
💾 Checkpointing
PostgresSaver persists full graph state after each node. Enables: resume after crash, pause-for-human-input, time-travel debugging, audit replay. thread_id maps to workflow_instance_id for traceability.
PostgresSaverTime-travel
👤 Human-in-the-Loop
interrupt_before / interrupt_after on designated nodes. Graph suspends, serialises state to PostgreSQL. Task-service creates human task. On task completion, graph resumes from exact checkpoint. Zero state loss.
InterruptResume
🔄 Reflexion / Self-Critique
Critique node re-evaluates LLM output: checks for missing regulatory citations, vague recommendations, incomplete checklists. If critique_score < threshold AND count < 3 → loop back to llm_review with critique appended. Prevents hallucinated compliance output.
ReflexionMax loops: 3

Fan-out via Send() API: batch_anomaly graph processes each batch record in parallel subgraph. Results merged by aggregation node. Controlled concurrency via semaphore (max 5 parallel LLM calls per workflow instance).

💾 Episodic Memory
Each agent maintains episodic memory (past task completions, outcomes, corrections received). Stored in Qdrant vector store. Retrieved at agent init via semantic similarity to current task. Enables agents to learn from past deviations and improve recommendations over time.
QdrantSemantic Recall
🔧 Tool Registry
Each specialist agent is provisioned a curated tool set: Triage gets regulatory_lookup; RCA gets batch_history_query + process_param_lookup; CAPA gets sop_search + training_record_query. Prevents scope creep between roles.
Scoped ToolsRole Isolation
Agent Memory Architecture — Three Tiers
🟡 Working Memory (In-context)
Current task state, intermediate results, tool call history. Lives in LLM context window. Managed via LangGraph state dict. Cleared on task completion.
🔵 Episodic Memory (Vector Store)
Past task summaries embedded and stored in Qdrant. Retrieved by cosine similarity at task start. Gives agents domain experience without retraining. TTL: 180 days.
🟢 Semantic Memory (Knowledge Base)
Static regulatory documents (ICH Q10, 21 CFR 211, internal SOPs) chunked and indexed in Qdrant. Read-only. Updated via RAG ingestion pipeline on SOP change.

mTLS between all services (Envoy sidecar)
NetworkPolicy: deny-all default + explicit allows
LLM gateway internal-only (no external ingress)
WAF rules on ingress (OWASP CRS)
Qdrant: internal-only, no external exposure
VPC with private subnets for all data stores
📋 GxP Compliance
21 CFR Part 11: electronic records + e-signatures
Hash-chained audit log (SHA-256 prev_hash)
eSign: meaning, reason, re-auth required
All LLM calls audited to audit-core (AuditCallbackHandler)
LangGraph state checkpoints = tamper-evident workflow history
SOC 2 Type II controls mapped to services
🤖 AI / LLM Security
Prompt injection detection via Semgrep rules in CI
Model output validated against Pydantic schemas before use
LLM model allow-list enforced in gateway (no arbitrary models)
DeepAgent tool calls scoped by role — read-only SQL only
Max token limits enforced per agent type
No PII in prompts — data pseudonymised before LLM call
🔐 Data Security
Encryption at rest: AES-256 for all volumes
Encryption in transit: TLS 1.3 everywhere
PII fields column-encrypted (Fernet) in PostgreSQL
Vault dynamic secrets — no long-lived credentials
MinIO SSE-S3 for object encryption
Qdrant payloads encrypted at rest

Rate limiting: Redis counters + Envoy rate-limit filter
SIEM integration via audit event stream
Automated CVE patching via Renovate bot
Anomalous LLM token spend triggers alert (possible prompt injection)
